# 「每日论文精选展示」网页设计参考 · 网站调研报告

> 调研目的：为「三维重建（3D Reconstruction）× 世界模型（World Model）方向的每日论文检索与展示网页」挑选可借鉴的设计模板。
> 调研日期：2026-08-27
> 调研方式：实际访问 / 接口检索确认站点存在，再从「每日多篇论文扫读体验」角度评估。
> 每篇论文计划展示：标题/作者/机构/来源、旧论文（被引·GitHub star·顶会标注）、新论文（作者影响力）、摘要+Intro 总结、Method 总结、流程图（method figure）、个人审阅标记（喜欢/不喜欢+原因）。

## 二、逐站详评

### 1. HuggingFace Daily Papers —— 每日热度卡片流的标杆
- **URL**：https://huggingface.co/papers
- **布局风格**：单栏纵向**卡片流**，按「当天日期」分组（每天一组）；每张卡片含缩略图（论文首页 figure）、标题、作者、机构、一句话摘要、社区上/下投票数与评论数。信息密度中等偏高，一屏约 4–6 篇。
- **视觉风格**：浅色现代极简，HF 品牌橙做强调色；无衬线字体、大量留白；**论文缩略图位置醒目**（左图右文）。明暗主题随站点。
- **优点（扫读角度）**：
  - 「按天分组 + 热度投票」天然契合「每日精选」；投票数就是快速筛选信号。
  - 缩略图（多为 method/teaser figure）直接进卡片，**正好对应你要的流程图位置**。
  - 卡片层级清晰：图 → 标题 → 一句话 → 元信息，扫读路径短。
- **缺点**：
  - 无「方法总结/Intro 总结」的长文区块，摘要较短。
  - 被引数、GitHub star、顶会徽章不是一等公民（需跳转）。
  - 没有个人「喜欢/不喜欢 + 原因」的偏好记录位。
- **适合模仿的具体理由**：**整体骨架直接可抄**——按日期分组的卡片流 + 左图右文 + 热度信号。你只需在卡片内扩出「旧论文指标（被引/star/顶会）」与「个人审阅标记」两个区块，就是你要的形态。

### 2. Papers with Code —— 指标/代码/榜单的信息密度标杆
- **URL**：https://paperswithcode.com
- **布局风格**：双模式——**论文列表流** + **任务（Task）/SOTA 榜单**视图；多栏，列表项含标题、摘要、任务标签、GitHub 仓库 star 数、数据集/方法链接。信息密度高。
- **视觉风格**：浅色、工具感强、克制；用彩色小徽章标注任务（如 "3D Reconstruction"、"Novel View Synthesis"）与 SOTA；缩略图较小、以文字元信息为主。
- **优点（扫读角度）**：
  - **GitHub star 数、代码链接、任务分类**是一等公民——直接对应你「旧论文看 star/顶会」的需求。
  - 任务/方法/数据集的结构化标签体系，非常适合给 3D 重建、世界模型论文打类目。
  - 榜单视图可迁移成「本周/本方向高价值论文榜」。
- **缺点**：
  - 偏「检索/查榜」工具，**每日更新的时间叙事弱**，没有「今天新增」的杂志感。
  - 视觉较朴素，缩略图不突出，长文总结位缺失。
- **适合模仿的具体理由**：抄它的**元信息徽章系统**（star 数、任务标签、会议/来源标签、SOTA 标记）和**结构化字段排布**，把这些做成每张论文卡片上的指标条。

### 3. alphaXiv —— 图 + AI 一句话总结的扫读体验王者
- **URL**：https://www.alphaxiv.org
- **布局风格**：按**日期时间线**的卡片/瀑布流混排，卡片大图 + 标题 + **AI 生成的一段话总结**（本文实际抓取即见：每条论文下紧跟一段讲清「做了什么、效果数字」的中文/英文摘要），并聚合讨论。信息密度中等，图占比大。
- **视觉风格**：现代、轻杂志感；大图 teaser、圆角卡片、强调色克制；明暗皆可。
- **优点（扫读角度）**：
  - **「一句话讲清贡献 + 关键数字」**的卡片摘要，扫读效率最高——本次抓取可见如「success rate 46.95%」「14.4× 提速」直接写在卡片上。
  - 大图位天然放 method/teaser figure。
  - 按天时间线 + 研究者档案（/researchers），**研究者影响力可迁移成你要的「新论文作者影响力标注」**。
- **缺点**：
  - AI 摘要质量参差，需人工/二次校验（你的场景正好有人工审阅环节）。
  - 被引、star 等硬指标呈现弱于 Papers with Code。
- **适合模仿的具体理由**：抄它的**卡片摘要写法范式**（一句话贡献 + 量化结果）与**大图位**；你的「摘要+Intro 总结」「Method 总结」可做成卡片内「一句话层 + 展开详情层」两级。

### 4. arXiv 每日列表页（cs.CV / cs.LG recent）—— 数据源本体，反例参照
- **URL**：https://arxiv.org/list/cs.CV/recent （本次实际抓取确认，按天列 100+ 条）
- **布局风格**：纯**编号单栏列表**，每条只有 arXiv 编号、标题、pdf/html 链接；超高密度、零视觉层级。
- **视觉风格**：无装饰、纯文本、经典学术极简。
- **优点**：**这是你的数据源头**——每日新论文最全、最权威，编号/标题/分类可靠，适合做抓取层。
- **缺点（扫读角度）**：无图、无摘要、无指标、无排序，一天上百条根本扫不动——**是典型「不要做成这样」的反例**。
- **适合模仿的具体理由**：只作为**数据接入与字段规范参照**（arXiv ID、分类、pdf/html 链接格式），视觉上零借鉴。arxiv-sanity 类站点（如 arxiv-sanity-lite）思路类似但加了推荐排序，可作理念参考。

### 5. Emergent Mind —— 趋势热度 + 话题/作者聚合
- **URL**：https://www.emergentmind.com （本次实际抓取确认）
- **布局风格**：**卡片流** + 顶部 Papers / Topics / Authors 三个 tab 与时间范围筛选；每篇聚合 arXiv 摘要、社交讨论（X/Reddit/GitHub 热度）、AI 问答。
- **视觉风格**：现代 SaaS 产品感、卡片化、深色友好；热度/话题徽标丰富。
- **优点（扫读角度）**：
  - **「哪些论文在网上火了」的趋势信号**强，适合每日筛高价值。
  - Topics/Authors 双维聚合，正好可做「3D 重建」「世界模型」话题页与作者影响力页。
  - 卡片内含 AI 总结 + 讨论入口，信息层次丰富。
- **缺点**：
  - 功能偏多偏「平台」，个人化审阅/偏好记录不是重点。
  - 社交热度对严肃学术价值有噪声。
- **适合模仿的具体理由**：抄它的**话题(tab)+时间范围筛选**信息架构，以及**作者/话题聚合页**思路来承载「作者影响力标注」。

### 6. The Batch（DeepLearning.AI）—— 人工精选 + 短评的叙事范式
- **URL**：https://www.deeplearning.ai/the-batch/ （本次实际抓取确认）
- **布局风格**：**周刊时间线**，单栏；每一期是一个大标题（当周几件大事）+ 编辑短评，点进去是分条新闻/研究，配分类标签（Research / Business / Science…）。
- **视觉风格**：编辑杂志风、配图、舒适行距、人文感强。
- **优点（扫读角度）**：
  - **「人工精选 + 一句话点评 + 为什么重要」**的叙事最适合「每日精选」的人情味。
  - 分类标签 + 期号归档，迁移成「每日一期」的归档结构很顺。
- **缺点**：
  - 是周刊而非论文级卡片，无论文 method 图/指标等结构化字段。
  - 偏新闻，学术元信息少。
- **适合模仿的具体理由**：抄它的**「编辑短评 / 为什么值得看」语气与每日一期的归档感**——正好对应你「个人审阅标记（喜欢/不喜欢+原因）」的人味总结区块。

### 7. Semantic Scholar —— 检索与 TLDR 摘要
- **URL**：https://www.semanticscholar.org （本次实际抓取确认，2.37 亿篇索引）
- **布局风格**：搜索结果**列表** + 论文详情页；有著名的 **TLDR（一句话作者级摘要）**、被引数、影响力引用（Influential Citations）。
- **视觉风格**：学术工具风、浅色、克制。
- **优点**：**被引数 / 影响力引用 / TLDR** 字段权威——直接对应旧论文「被引次数」与快速摘要；可作为数据源/API。
- **缺点**：以搜索为中心，**没有每日更新流**，缩略图与 method 图缺失，扫读新鲜感弱。
- **适合模仿的具体理由**：抄它的 **TLDR 一句话摘要** 与 **影响力引用(Influential Citations) 指标**呈现方式，用于旧论文价值标注。

### 8. awesome_3DReconstruction_list（openMVG）—— 方向经典论文的沉淀范式
- **URL**：https://github.com/openMVG/awesome_3DReconstruction_list （经 GitHub API 确认存在："A curated list of papers & resources linked to 3D reconstruction from images"）
- **布局风格**：**分类目录式长列表**（awesome 风），按子方向（SfM/MVS/NeRF/立体匹配等）分组，每条一行：标题 + 链接 + 会议/年份。
- **视觉风格**：Markdown 纯文本、链接清单、零装饰。
- **优点**：**方向经典论文的权威沉淀**，适合做「旧论文/必读经典」专区骨架；分类体系可直接复用。
- **缺点**：纯静态清单、无图、无每日更新、无扫读卡片体验。
- **适合模仿的具体理由**：不抄视觉，抄它的**子方向分类法**与「经典必读」沉淀思路，作为网页里「经典论文 / 资料库」板块的信息架构。

## 三、Top 推荐（结论）

综合「每日多篇扫读效率 + 你要展示的字段（图、指标、总结、作者影响力、个人标记）」，推荐以 **3 个站点组合借鉴**，而不是单抄一个：

### 🥇 主骨架：HuggingFace Daily Papers + alphaXiv
- **HF Daily Papers** 提供整体信息架构：**按天分组的单栏卡片流 + 左图右文 + 热度信号**，最贴合「每天更新、当天一组」的心智。
- **alphaXiv** 提供卡片内容范式：**大图(method/teaser figure) + 一句话贡献+关键数字的 AI 摘要**，扫读最快；其 researchers 页可迁移为「作者影响力」。
- 二者合并 = 你要的「图 + 快速总结 + 每日流」主体。

### 🥈 指标系统：Papers with Code（+ Semantic Scholar 补被引）
- 抄 Papers with Code 的**元信息徽章条**：GitHub star、任务标签、来源/顶会徽章、SOTA 标记。
- 用 Semantic Scholar 的**被引数 / Influential Citations / TLDR** 补齐旧论文的学术价值字段。
- 这样旧论文看「被引 + star + 顶会徽章」、新论文看「作者影响力 + 热度」的双轨指标就齐了。

### 🥉 个性化与归档：The Batch
- 抄它的**「编辑短评 / 为什么值得看」语气**和**每日一期的归档结构**，承载你的**个人审阅标记（喜欢/不喜欢 + 原因）**，把冷冰冰的论文流变成带个人判断的精选日志。

**一句话落地方案**：
> 用 **HF Daily Papers 的按天卡片流** 搭骨架 → 卡片内用 **alphaXiv 的大图 + 一句话总结** → 卡顶加 **Papers with Code 式指标徽章条（star/顶会/任务）** → 旧论文补 **Semantic Scholar 被引/TLDR**、新论文补 **作者影响力** → 卡底加 **The Batch 式「我的点评/喜欢与否+原因」**。arXiv 列表页只作数据抓取源，awesome 列表只作「经典必读」分类参考，二者视觉上不借鉴。
